# Aula 01 — Variáveis e subtração em Python

## Objetivo

Usar variáveis para guardar uma meta e o valor já economizado, subtrair os valores e exibir quanto falta.

## Código escrito na aula guiada

`main.py` contém a solução que o estudante escreveu durante a aula. O exercício foi resolvido por raciocínio; o código ainda não foi executado localmente.

## Conceitos praticados

- `meta`, `guardado` e `falta` são nomes de variáveis.
- `=` atribui um valor à variável.
- `-` faz a subtração.
- `print(falta)` mostra o valor da variável.
- `print("falta")` mostraria o texto `falta`.

## Exemplo

Com uma meta de 20.000 e 8.000 guardados, o programa deve mostrar:

```text
12000
```
