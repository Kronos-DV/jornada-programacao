## Organização

Cada atividade terá sua própria pasta, com os exercícios e um README explicando objetivo, conceitos praticados, dificuldades e execução ou visualização. As entregas serão registradas em commits separados, depois de concluídas e revisadas.

Os exercícios de desenvolvimento web frontend da faculdade, com foco em HTML5, serão adicionados em pastas como `faculdade/html5/atividade-01/` quando estiverem concluídos. Essa etapa está planejada; ainda não há uma entrega de HTML5 neste repositório.

Projetos maiores poderão ter repositórios próprios.
