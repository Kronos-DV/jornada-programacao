## Organização

Cada atividade terá sua própria pasta, com os exercícios e um README explicando objetivo, conceitos praticados, dificuldades e execução ou visualização. As entregas serão registradas em commits separados, depois de concluídas e revisadas.

O [Elo Solidário](https://github.com/Kronos-DV/elo-solidario) já faz parte dos estudos de HTML5 da faculdade e permanece em seu repositório próprio. É um site acadêmico de uma ONG fictícia, com páginas de apresentação, projetos e cadastro demonstrativo. Foi desenvolvido com apoio de IA e está sendo usado para aprofundar a compreensão de estrutura semântica, links, imagens e formulários. Seu [README](https://github.com/Kronos-DV/elo-solidario/blob/main/README.md) detalha os recursos, a execução e as limitações.

Novos exercícios menores de HTML5 poderão ser adicionados em pastas como `faculdade/html5/atividade-01/`, após a conclusão e revisão, com README e commit próprios.

Projetos maiores poderão ter repositórios próprios.
